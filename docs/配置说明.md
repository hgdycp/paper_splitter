## 一、配置文件格式

### 1.1 支持的格式

- YAML (.yaml, .yml)
- JSON (.json)
- Python (.py)

### 1.2 加载配置

```python
from src.config import Config

# 加载默认配置
config = Config.load()

# 加载自定义配置
config = Config.load("config/custom.yaml")

# 获取配置项
dpi = Config.get("pdf.dpi", default=300)
```

### 1.3 命令行覆盖

命令行参数会覆盖配置文件中的设置：

```bash
python -m src.main test.pdf --dpi 600
```

## 二、PDF处理配置

**配置路径**: `pdf.*`

### 2.1 可用配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `pdf.dpi` | int | 300 | PDF转图像的分辨率 |
| `pdf.first_page` | int | None | 处理的起始页（None=首页） |
| `pdf.last_page` | int | None | 处理的结束页（None=末页） |
| `pdf.max_pages` | int | None | 最大处理页数 |
| `pdf.password` | str | None | PDF密码（如有） |

### 2.2 示例

```yaml
pdf:
  dpi: 300
  first_page: 1
  last_page: null
  max_pages: 100
```

## 三、图像处理配置

**配置路径**: `image.*`

### 3.1 可用配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `image.binarize.enabled` | bool | True | 是否启用二值化 |
| `image.binarize.threshold` | int | 127 | 二值化阈值 (0-255) |
| `image.denoise.enabled` | bool | True | 是否启用去噪 |
| `image.denoise.method` | str | "gaussian" | 去噪方法 |
| `image.contrast.enabled` | bool | True | 是否增强对比度 |
| `image.contrast.alpha` | float | 1.5 | 对比度系数 |
| `image.contrast.beta` | int | 0 | 亮度调整值 |
| `image.resize.enabled` | bool | False | 是否调整尺寸 |
| `image.resize.width` | int | None | 目标宽度 |
| `image.resize.height` | int | None | 目标高度 |
| `image.resize.scale` | float | None | 缩放比例 |

### 3.2 去噪方法选项

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| `gaussian` | 高斯模糊 | 轻度噪声 |
| `median` | 中值滤波 | 椒盐噪声 |
| `bilateral` | 双边滤波 | 保持边缘去噪 |

### 3.3 示例

```yaml
image:
  binarize:
    enabled: true
    threshold: 127
  denoise:
    enabled: true
    method: "gaussian"
  contrast:
    enabled: true
    alpha: 1.5
    beta: 10
```

## 四、题目检测配置

**配置路径**: `detector.*`

### 4.1 可用配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `detector.min_question_height` | int | 20 | 最小题目高度(像素) |
| `detector.max_question_height` | int | 2000 | 最大题目高度(像素) |
| `detector.question_number_patterns` | List[str] | 见下文 | 题目序号正则模式 |
| `detector.section_patterns` | List[str] | 见下文 | 大题标题正则模式 |
| `detector.ocr_lang` | str | "chi_sim+eng" | OCR识别语言 |
| `detector.ocr_config` | str | "" | Tesseract额外配置 |
| `detector.include_answer_area` | bool | True | 是否包含答题区域 |
| `detector.answer_area_padding` | int | 10 | 答题区域边距 |

### 4.2 默认正则模式

**题目序号模式**:
```python
[
    r"^\d+[.、]",               # 阿拉伯数字: 1. 2、 3.
    r"^[一二三四五六七八九十]+[.、]",  # 中文数字: 一. 二、 三.
    r"^第[一二三四五六七八九十]+[题节]",  # 第X题 第X节
]
```

**大题标题模式**:
```python
[
    r"^选择题$",
    r"^填空题$",
    r"^解答题$",
    r"^计算题$",
    r"^证明题$",
    r"^作图题$",
]
```

### 4.3 示例

```yaml
detector:
  min_question_height: 20
  max_question_height: 2000
  question_number_patterns:
    - '^\d+[.、]'
    - '^[一二三四五六七八九十]+[.、]'
    - '^第[一二三四五六七八九十]+题'
  section_patterns:
    - '^选择题$'
    - '^填空题$'
    - '^解答题$'
  ocr_lang: "chi_sim+eng"
  include_answer_area: true
  answer_area_padding: 10
```

## 五、分割输出配置

**配置路径**: `output.*`

### 5.1 可用配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `output.dir` | str | "./output" | 输出目录 |
| `output.format` | str | "png" | 输出格式 |
| `output.prefix` | str | "Q" | 文件名前缀 |
| `output.quality` | int | 95 | JPG质量 (1-100) |
| `output.naming` | str | "number_type" | 命名规则 |
| `output.create_summary` | bool | True | 是否生成汇总文件 |
| `output.overwrite` | bool | False | 是否覆盖已有文件 |

### 5.2 命名规则选项

| 规则 | 示例 | 说明 |
|------|------|------|
| `number` | Q01.png | 仅题号 |
| `number_type` | Q01_选择题.png | 题号_类型 |
| `type_number` | 选择题_01.png | 类型_题号 |

### 5.3 示例

```yaml
output:
  dir: "./output"
  format: "png"
  prefix: "Q"
  quality: 95
  naming: "number_type"
  create_summary: true
  overwrite: false
```

## 六、完整配置示例

### 6.1 YAML 格式

```yaml
# 试卷分割系统配置

pdf:
  dpi: 300
  first_page: null
  last_page: null
  max_pages: null

image:
  binarize:
    enabled: true
    threshold: 127
  denoise:
    enabled: true
    method: "gaussian"
  contrast:
    enabled: true
    alpha: 1.5
    beta: 0

detector:
  min_question_height: 20
  max_question_height: 2000
  question_number_patterns:
    - '^\d+[.、]'
    - '^[一二三四五六七八九十]+[.、]'
    - '^第[一二三四五六七八九十]+题'
  section_patterns:
    - '^选择题$'
    - '^填空题$'
    - '^解答题$'
    - '^计算题$'
  ocr_lang: "chi_sim+eng"
  include_answer_area: true
  answer_area_padding: 10

output:
  dir: "./output"
  format: "png"
  prefix: "Q"
  quality: 95
  naming: "number_type"
  create_summary: true
  overwrite: false
```
