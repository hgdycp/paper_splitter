## 三、模块开发说明

### 3.1 PDF处理模块 (pdf_processor.py)

**职责**: 加载PDF，转换为图像

**开发要点**:
- 使用 PyMuPDF 处理 PDF 渲染
- 支持多页批量转换
- 注意内存管理，大PDF分页处理

```python
# 示例：自定义PDF处理器
class CustomPDFProcessor(PDFProcessor):
    def __init__(self, file_path):
        super().__init__(file_path)

    def pdf_to_images(self, dpi=300):
        # 自定义实现
        pass
```

### 3.2 图像处理模块 (image_processor.py)

**职责**: 图像预处理，提升OCR效果

**开发要点**:
- 使用 OpenCV 进行图像处理
- 保持原始图像不变，返回处理后的副本
- 提供可配置的预处理流程

### 3.3 题目检测模块 (question_detector.py)

**职责**: 检测题目位置和边界

**开发要点**:
- 使用 pytesseract 进行文字识别
- 支持自定义题目序号匹配模式
- 返回标准化的区域坐标格式

### 3.4 分割输出模块 (splitter.py)

**职责**: 按检测到的区域分割图像并输出

**开发要点**:
- 支持多种输出格式
- 自动创建输出目录
- 返回文件路径列表供后续使用

### 4.2 调试脚本

创建 `debug_script.py`:

```python
from src.pdf_processor import PDFProcessor
from src.image_processor import ImageProcessor
from src.question_detector import QuestionDetector

# 加载图像
processor = PDFProcessor("test.pdf")
images = processor.pdf_to_images(dpi=300)

# 预处理
img_proc = ImageProcessor(images[0])
processed = img_proc.preprocess()

# 检测
detector = QuestionDetector()
questions = detector.detect_questions(processed)

# 打印结果
for q in questions:
    print(q)
```

### 4.3 可视化调试

```python
import cv2

def debug_visualize(image, questions):
    """可视化调试题目检测结果"""
    for q in questions:
        x, y, w, h = q['bbox']
        cv2.rectangle(image, (x, y), (x+w, y+h), (0, 255, 0), 2)
        cv2.putText(image, q['number'], (x, y-5),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 2)
    cv2.imwrite("debug_output.png", image)
```

### 6.2 编写测试

```python
import pytest
import numpy as np
from src.image_processor import ImageProcessor

class TestImageProcessor:
    def test_binarize(self):
        """测试二值化功能"""
        # 创建测试图像
        img = np.zeros((100, 100), dtype=np.uint8)
        img[40:60, 40:60] = 200

        processor = ImageProcessor(img)
        result = processor.binarize(threshold=127)

        # 验证结果
        assert result.shape == img.shape
        assert result.min() == 0
        assert result.max() == 255

    def test_load_invalid_file(self):
        """测试加载无效文件"""
        processor = ImageProcessor()
        with pytest.raises(FileNotFoundError):
            processor.load("nonexistent.png")
```
