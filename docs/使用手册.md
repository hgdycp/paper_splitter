## 二、基本操作

### 2.1 添加文件

1. 点击「添加文件」按钮
2. 在弹出的文件选择框中选择 PDF 或图片文件
3. 支持多选（按住 Ctrl 多选）

### 2.2 添加文件夹

1. 点击「添加文件夹」按钮
2. 选择包含试卷文件的文件夹
3. 系统会自动识别所有支持的格式

### 2.3 设置输出选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 输出目录 | 分割结果保存位置 | ./output |
| 输出格式 | 图像格式 | PNG |
| DPI | 图像分辨率 | 300 |
| 包含答题区 | 是否保留答题区域 | 是 |

### 2.4 开始分割

1. 确保文件列表中有待处理文件
2. 设置好输出选项
3. 点击「开始分割」按钮
4. 等待处理完成，查看结果

### 2.5 查看结果

- 分割完成后自动打开输出目录
- 在文件列表中查看每题的分割结果
- 点击可在预览区查看大图

## 三、命令行参数

### 3.1 基本用法

```bash
python -m src.main <输入文件> [选项]
```

### 3.2 参数说明

| 参数 | 缩写 | 说明 | 默认值 |
|------|------|------|--------|
| --output | -o | 输出目录 | ./output |
| --format | -f | 输出格式 (png/jpg/pdf) | png |
| --dpi | -d | 图像DPI | 300 |
| --no-answer | -n | 不包含答题区域 | False |
| --batch | -b | 批量处理模式 | False |
| --help | -h | 显示帮助信息 | - |

### 3.3 使用示例

```bash
# 基本用法
python -m src.main test.pdf

# 指定输出目录和格式
python -m src.main test.pdf -o ./results -f jpg

# 批量处理
python -m src.main ./papers -b -o ./output

# 高分辨率输出
python -m src.main test.pdf -d 600
```

### 3.4 配置文件

支持通过配置文件传递参数：

```bash
python -m src.main test.pdf --config config/my_config.yaml
```

## 五、常见问题

### Q1: 分割结果不准确怎么办？

**A**: 检查以下几点：
- 确保试卷图像清晰，光照均匀
- 调整 DPI 设置（建议 300 或更高）
- 检查 Tesseract OCR 是否正确安装

### Q2: 题目漏检或误检怎么办？

**A**: 可以通过修改配置优化：
- 调整 `question_number_patterns` 匹配模式
- 修改 `min_question_height` 最小高度阈值
- 检查图像预处理效果

### Q3: 如何处理答题卡和试卷在一起的密铺试卷？

**A**: 使用 `--no-answer` 参数排除答题区域，或在配置中启用 `detect_answer_area` 功能。

### Q4: 支持哪些输入格式？

**A**: 目前支持：
- PDF 文件
- PNG 图片
- JPG/JPEG 图片
- BMP 图片

### Q5: 处理速度很慢怎么办？

**A**: 建议：
- 降低 DPI 设置（如 150）
- 使用批量处理而非逐个处理
- 确保有足够的内存
